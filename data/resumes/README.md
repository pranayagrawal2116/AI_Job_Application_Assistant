# Resumes Directory

Place your latest resume file (PDF or DOCX format) here.

### Usage Instructions:
1. Copy your resume file into this directory (e.g., `resume.pdf`).
2. Update the `CANDIDATE_RESUME_PATH` variable in `.env` or reference the filename in `config/config.yaml`.
3. In Phase 7, the application preparer will read your resume locally to extract verified projects, technical skills, and achievements.

### Privacy & Security:
- All files in this folder (except this `README.md`) are git-ignored.
- Your resume is stored locally and will never be shared, uploaded, or transmitted anywhere without your explicit confirmation.
