# Persistent Storage Directory

This directory stores the local SQLite database (`job_assistant.db`) and any SQLite migration or backup files.

### Contents:
- `job_assistant.db`: Generated in Phase 2 for job application persistence, tracking, and status management.

### Privacy & Security:
- Database files (`*.db`, `*.sqlite`, `*.sqlite3`) are strictly excluded by `.gitignore` to protect personal job hunt history and notes.
